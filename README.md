# 🌌 KVARON_X (KRX)

**KVARON_X** — масштабная многофункциональная социальная и развлекательная экосистема. Платформа объединяет классическую социальную сеть, игровые турниры, музыкальный стриминг и глубокую систему геймификации с уровнями и кастомизацией.

---

## 🎨 Design Philosophy

Визуальный стиль построен на строгом монохромном минимализме:
- **Фон:** `#000000` — глубокий чёрный
- **UI-элементы и текст:** `#FFFFFF` — чистый белый
- **Анимации:** fade-in переходы, микро-интеракции, эффект огня для 500 УРВ
- **Живые обои:** эксклюзивно для Администраторов (фон всего интерфейса)

---

## 🚀 Key Features

- **Социальная сеть:** лента постов, истории (Instagram-style), KRX Pulse (TikTok/Shorts-style)
- **Геймификация:** прогрессия до 500 УРВ (Абсолют), валюта KRX, кастомизация профиля
- **Игровая экосистема:** комнаты до 200 человек, официальные турниры с призовыми фондами
- **Музыка:** встроенный плеер (Spotify-style), личные библиотеки, загрузка треков
- **Кланы:** сообщества с авто-верификацией при 500 000 участников
- **Приватность:** жёсткая логика Чёрного списка — полная блокировка контента
- **Экономика:** валюта KRX, кошелёк, переводы, магазин цифровых товаров

---

## 🏆 Система уровней (500 УРВ)

| Этап | Уровни | Ключевые награды |
|------|--------|-----------------|
| Начальный | 1–70 | +10–70 KRX за уровень |
| Элитный | 80–250 | +100–3000 KRX, GIF-аватары на 100 УРВ |
| Высший | 300–450 | +4000–7500 KRX, баннеры на 300, обои на 400 |
| Финальный | 500 | +10 000 KRX, красная галочка с огнём 🔥 |

## 📁 Структура репозитория

```
KVARON_X/
├── assets/
│   ├── branding/        # Логотипы, иконки, системная графика
│   ├── animations/      # Эффекты рангов, свечения, огонь
│   └── sounds/          # Звуки уведомлений и интерфейса
├── config/
│   ├── database/        # Схемы БД, подключения
│   └── security/        # Валидация паролей, анти-спам
├── frontend/
│   ├── styles/          # CSS/SCSS — монохромная тема
│   ├── scripts/         # Клиентская логика
│   ├── components/      # Модальные окна, плеер, кнопки
│   └── modules/
│       ├── core/        # Главная, Новости, Уведомления
│       ├── social/      # Кланы, Друзья, Чат, ЧС
│       ├── entertainment/ # Игры, Музыка
│       ├── personal/    # Профиль, Кошелёк, Настройки
│       └── store/       # Магазин товаров и подарков
├── backend/
│   ├── controllers/     # Обработчики запросов
│   ├── models/          # Юзеры, Уровни, Транзакции
│   ├── middlewares/     # Права, ЧС, безопасность
│   └── services/        # Telegram-бот, платёжные шлюзы
└── admin-panel/
    ├── moderation/      # Баны, муты, ограничения
    ├── analytics/       # Дашборды онлайна и активности
    └── audit-logs/      # История всех системных действий
```
